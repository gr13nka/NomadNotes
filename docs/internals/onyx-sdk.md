# Onyx SDK — vendored artifacts and licensing

### The vendored Onyx Pen SDK artifacts are BSD 3-Clause, not Apache 2.0
The `onyxsdk-pen`, `onyxsdk-device` and `onyxsdk-base` artifacts under `third_party/boox-m2` are released by Onyx under the BSD 3-Clause License. The Apache 2.0 license on `onyx-intl/OnyxAndroidDemo` covers only that repository's sample code, not the build artifacts. Onyx support confirmed this in writing to the project author on 2026-09-21: the SDK is free of charge, no separate commercial license is required, the artifacts may be bundled in a closed-source app and distributed through Google Play and direct APK download, and they may be kept in a private repository and build system. The required notice is `Copyright (c) 2026 ONYX INTERNATIONAL INC. All rights reserved.`
- **Anchors:** `settings.gradle.kts` (`dependencyResolutionManagement/repositories`, the `third_party/boox-m2` maven repo), `pen-onyx/build.gradle.kts` (`dependencies`, `libs.onyxsdk.pen`)
- **Why it matters:** none of the vendored `.pom` or `.jar`/`.aar` files carry a license block, so the licence cannot be read off the tree and the demo repo's Apache 2.0 is the misleading answer a reader reaches first. This is the fact that unblocks charging for the app or shipping it closed-source. Two caveats: Onyx says Google Play's security scan may error because the SDK reaches system functions by reflection, which can affect the listing; and the vendored tree also holds artifacts the letter did not name (`onyxsdk-baselite`, `onyxsdk-geometry`, `onyxsdk-commons-io`, `onyxsdk-penbrush`, `onyxsdk-pennative`, plus Tencent's `mmkv`), whose terms were not confirmed.
